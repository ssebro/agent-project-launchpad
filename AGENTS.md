# Working in this repository

- Make changes on a focused branch (`fix/…`, `feat/…`, or `chore/…`), never on `main`.
- Start new work from the current remote `main`; keep unrelated changes in separate PRs.
- Open a pull request for every change. Do not push directly to `main` or merge
  without the maintainer's explicit instruction.
- Run relevant tests before requesting review. Report checks that could not run.
- Address CI failures and review findings on the same branch; do not treat an
  automated review as permission to merge.
- Follow CONTRIBUTING.md. Use fictional fixtures; never commit personal agent
  histories, credentials, handoffs, or runtime state.
