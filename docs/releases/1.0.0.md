# Agent Project Launchpad 1.0.0

Pick up your work with Codex, Claude Code, or GitHub Copilot CLI. Type your usual
agent command, choose a project, and continue with shared notes and recent context.

- Discover and resume existing local conversations across all three agents.
- Start a new conversation with Enter by default, or use `n` anywhere in the picker.
- Search, rename, complete/reopen, archive/undo, and request reviewed summaries.
- Show the previous agent separately from the agent you will continue with.
- Preserve project identity and activity during empty visits, incomplete histories,
  and interrupted launches. Real conversations still count without file edits.
- Enable the picker for normal agent commands with backed-up bash/zsh integration.

## Install

Requires macOS or Linux, Python 3.10+, pipx, and an installed,
authenticated agent. On Windows, use WSL.

```sh
pipx install agent-project-launchpad
agent-launchpad setup
```

Open a new Terminal and type `claude`, `codex`, or `gh copilot`.

PyPI provides the package for pipx installation. GitHub Releases provides the
matching wheel and source archive.
See the user guide and compatibility notes for native session-format limits and
what project context carries between agents.
