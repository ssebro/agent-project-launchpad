# Agent Project Launchpad 1.0.1

This patch release makes uninstalling the launcher easier to find.

- Run `agent-launchpad uninstall` to remove managed Bash or Zsh integration with
  a backup, then follow the printed package-removal steps for pipx or pip/venv.
- Preview changes with `--dry-run`; select a shell with `--shell` or a custom
  startup file with `--rc-file`.
- Saved launcher notes and native agent histories are kept. The existing
  `uninstall-shell` command remains supported.

## Upgrade

```sh
pipx upgrade agent-project-launchpad
```

For pip/venv installations, run `python -m pip install --upgrade agent-project-launchpad`
in that environment.

## Validation

All 116 automated tests pass. The installed setup/uninstall flow was also tested
in disposable Bash and Zsh environments, including backups, repeated uninstall,
dry runs, retained notes, fresh-shell command forwarding, and pip package removal.
